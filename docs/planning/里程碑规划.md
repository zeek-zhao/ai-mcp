## 1. 里程碑依赖关系

```
M0 ──▶ M1 ──▶ M2 ──▶ M5 (Gerrit)
 │      ├──▶ M3 ──▶ M6 (GitHub)
 │      └──▶ M4 ──▶ M7 (Jenkins)
 │                 └▶ M8 (Atlassian)
 └──▶ M3 ──▶ M9 (登录预检与环境自愈)
M5–M9 ──▶ M10 (Host 接入与验收)
```

- M5–M8 相互独立，可并行或按优先级排序。
- 前一里程碑合并入库后，再开始下一里程碑；不得跨里程碑提前实现。

## 2. 里程碑明细

### M0 · 仓库骨架与协作规范
**目标**：建立符合 GitHub 流程的仓库基础结构与规范文件。

**范围**
- 创建目标目录结构与占位文件。
- `.gitignore`：排除本地配置、日志、PID、虚拟环境、依赖目录、临时文件。
- Issue 模板（需求/任务/Bug）、PR 模板、CODEOWNERS。
- CI 工作流骨架：脚本语法解析、模板完整性、密钥扫描。
- 文档骨架与台账（见 `docs/`）。

**验收标准**
- 克隆后目录与计划书一致；模板齐全；CI 可触发并在空实现状态下通过。
- 本地配置示例不被 Git 跟踪。

**不做**：不实现总控菜单逻辑；不接入真实外部系统。

### M1 · 总控服务注册表
**目标**：用集中配置文件描述全部服务，后续菜单、启停、配置、状态逻辑复用此注册表。

**范围**
- `mcpctl.config.ps1` 服务数组：显示名、目录、启动命令、配置模板路径、本地配置路径、PID 文件、日志路径、技术栈。
- 全局参数：进程退出等待超时（默认 15 秒，遗留进程清理后等待消失用）、菜单语言（中文）、仓库根目录定位方式。
- 注册表读取基础函数，供 lib 脚本复用。

**验收标准**
- 四个服务条目字段完整；配置可被 PowerShell 正常解析。
- 新增服务只需追加一条，不改其他逻辑代码。

**不做**：不实现真实启动命令；不读取外部凭证。

### M2 · 配置向导
**目标**：全中文分步引导完成本地配置，凭证安全落盘。

**范围**
- 选择服务 → 复制模板为本地配置（已存在时询问覆盖/保留）。
- 逐条录入参数；Token/密码隐藏不回显；写入本地配置。
- 连通性测试入口占位（真实接口在 M5–M8 实现）。
- 配置就绪标记：配置文件存在且必填项非空。

**验收标准**
- 四个服务均有参数录入项；敏感字段不回显；日志无明文凭证。
- 必填项缺失时标记“未配置就绪”。

### M3 · 诊断与状态核心（传输模型：Host 拉起 stdio，见 ADR-006）
**目标**：实现服务诊断、握手探活、遗留进程识别与清理能力，复用注册表与就绪判断；服务进程由 Host 按需 stdio 拉起，总控不托管。

**范围**
- 状态检测：遗留 PID 文件、进程存在性、PID 复用识别（语义为遗留进程检测）。
- 启动命令诊断：StartCommand 是否回填、可执行文件是否可定位、配置是否就绪、依赖环境是否初始化，输出中文诊断表。
- MCP 握手探活：stdio 短时拉起并发送 initialize 验证响应，探活进程随超时强杀、不写 PID；可单服务调用，失败不影响其余。
- 遗留进程清理：诊断展示 → 二次确认 → taskkill 强杀进程树并清理 PID 残留；不做“优雅停止”托管。
- Host 配置片段导出：生成 Host 可用的 stdio 配置（不含明文凭证），默认写到仓库外本地文件。
- 状态表格输出（含配置就绪/依赖环境/命令回填/遗留进程列）；操作日志（不含敏感信息）。

**验收标准**
- 启动命令未回填时诊断给出中文提示，不抛异常。
- 探活单服务失败不影响其余服务。
- 遗留 PID 可识别、清理需二次确认。
- 导出的 Host 配置不含任何明文凭证。

### M4 · 依赖初始化 Bootstrap
**目标**：仓库内隔离初始化各服务依赖环境，不依赖系统全局包。

**范围**
- 遍历注册表，按技术栈在子目录创建独立虚拟环境/依赖目录。
- 依据锁定文件安装依赖；输出成功/失败/跳过汇总。
- 提供“仅检查环境”“重建环境”入口；失败项给出中文原因与下一步。

**验收标准**
- 不向全局 Python/Node 安装运行依赖；环境目录被 gitignore。
- 新机器克隆后执行 Bootstrap 可复现环境（占位状态下流程可跑通）。

### M5 · Gerrit 接入
**目标**：完成 `mcp-gerrit` 本地封装、配置与连通测试。

**范围**
- 选定 gerrit-mcp-server 实现并锁定版本；回填注册表启动命令。
- 配置项：地址、认证方式、凭证、可选多实例。
- 只读连通测试；写操作（投票、评论、改 reviewer）保留二次确认。
- 记录已验证 Gerrit 版本范围与兼容性结论。

**验收标准**
- 向导可完成录入；服务作为本地 stdio MCP 被 Host 发现；只读查询可用；凭证仅存本地。

### M6 · GitHub 接入
**目标**：完成 `mcp-github` 本地部署模式封装、配置与连通测试。

**范围**
- 官方 github-mcp-server 本地部署，锁定版本与运行方式入文档。
- 配置项：实例地址（github.com / GHES）、PAT、可选组织/仓库范围。
- 只读探活：查询当前授权用户；不使用远程托管端点作为主路径。

**验收标准**
- 本地进程可启动；只读探活成功；PAT 仅存本地，仓库不含真实 Token。

### M7 · Jenkins 接入（零插件）
**目标**：独立本地 MCP 进程远程调用 Jenkins REST API，实例零改造。

**范围**
- 社区独立 jenkins-mcp，锁定版本。
- 配置项：地址、用户名、API Token、可选多实例、只读模式开关。
- 工具：查询 job/构建/日志/队列；写操作默认二次确认，可配置只读。
- 只读探活：查询概览或当前用户信息；记录已验证 Jenkins 版本范围。

**验收标准**
- 全程不在 Jenkins 装插件或改配置；只读默认可用；高危操作有确认闸门。

### M8 · Atlassian 接入（Jira + Confluence）
**目标**：本地一体化 MCP 对接内网 Jira 与 Confluence（DC/Server）。

**范围**
- 社区本地一体化 Atlassian MCP，锁定版本。
- 配置项：Jira 地址、Confluence 地址、个人访问令牌、可选空间/项目范围。
- 工具按命名空间区分 Jira 与 Confluence；分别只读探活。
- 记录支持的 API 范围、DC/Server 兼容性与已知限制。

**验收标准**
- 一个本地进程覆盖 Jira + Confluence；内网可达；凭证仅存本地。

### M9 · 登录预检与环境自愈（原“登录常驻管理”已取消，理由见 ADR-006）
**目标**：Windows 登录时一次性预检依赖环境、本地配置与启动命令，提示问题并可选自动 Bootstrap；默认不拉起任何 MCP 进程。

**范围**
- 登录预检：遍历注册表，检查依赖环境（venv / node_modules / 本地二进制）、配置就绪标记、启动命令回填状态，输出中文汇总。
- 环境自愈：发现问题时可提示并调用 Bootstrap 自动修复，修复动作需用户在预检配置中显式允许。
- 进程边界：预检与自愈均不启动、不托管任何 MCP 服务进程（由 Host 按需拉起）。
- 菜单：预检立即执行 / 查看上次结果；登录触发是否启用由用户配置，默认关闭。

**验收标准**
- 预检不拉起任何 MCP 进程；问题项给出中文原因与下一步指引。
- 未开启登录触发时不创建计划任务；开启后仅做预检，不做常驻。

### M10 · Host 接入与端到端验收
**目标**：完成 Host 配置说明与全链路验收，形成可交付状态。

**范围**
- Host 接入示例（四个服务分别注册，本地 stdio；配置片段导出已在 M3 具备，此处回填真实启动命令）。
- 端到端自测清单：配置 → Bootstrap → 诊断 → Host 按需拉起 → Host 发现工具 → 只读调用 → Host 退出后无遗留进程。
- 文档一致性核对：全部文档与实现无“总控托管/优雅停止/登录常驻”残留表述（ADR-006 影响面）。
- 验收报告：已验证能力、已知限制、风险与演进建议（HTTP/SSE 常驻等列为演进，不在本期实现）。
- README 更新：快速开始、目录说明、故障排查。

**验收标准**
- 四个服务均可在 Host 被发现并完成一次只读调用；流程可在干净 Windows 环境复现；文档与实现一致。
