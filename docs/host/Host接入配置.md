> 本文档在 M10 回填可运行的 Host 配置示例；以下为结构占位。四个服务在 Host 中分别注册为独立 MCP 条目，本地 stdio 连接。

## 1. 接入原则

- Host 分别为 `mcp-gerrit`、`mcp-github`、`mcp-jenkins`、`mcp-atlassian` 注册独立条目。
- 启动命令指向仓库内脚本/服务入口，使用仓库相对路径或由总控脚本拉起。
- 凭证通过本地配置文件注入，不在 Host 配置中明文填写 Token。

## 2. 配置示例（占位，M10 回填）

### 2.1 Cursor / 兼容 MCP 的客户端
```json
{
  "mcpServers": {
    "gerrit": { "command": "", "args": [], "env": {} },
    "github": { "command": "", "args": [], "env": {} },
    "jenkins": { "command": "", "args": [], "env": {} },
    "atlassian": { "command": "", "args": [], "env": {} }
  }
}
```

### 2.2 Claude Desktop（占位）
- 配置文件位置与条目格式在 M10 按官方当前文档回填。

## 3. 接入验证清单

- [ ] 四个服务条目均被 Host 识别。
- [ ] 每个服务可完成一次只读探活调用。
- [ ] Host 配置中不含明文凭证。
- [ ] 停止服务后 Host 侧连接状态可正确反映。
