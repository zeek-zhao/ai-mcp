## 1. mcp-gerrit（Gerrit 代码评审）

| 项 | 内容 |
|---|---|
| 选型 | 社区/官方 gerrit-mcp-server（Python） |
| 运行形态 | 本地 stdio |
| 配置模板 | `mcp-gerrit/gerrit_config.sample.json` |
| 配置项 | 实例地址、认证方式、凭证（HTTP 密码/Token/Cookie，按所选实现）、可选多实例 |
| 规划能力 | 查询 change、获取 diff、添加评论、投票、增减 reviewer |
| 高危操作 | 投票、写评论、改 reviewer 需二次确认 |
| 连通测试 | 调用 Gerrit 只读接口验证地址与凭证 |
| 已验证版本 | 待 M5 回填 |
| 已知限制 | 待 M5 回填（REST API 差异、Windows 下 curl/认证兼容性） |

## 2. mcp-github（GitHub / GitHub Enterprise）

| 项 | 内容 |
|---|---|
| 选型 | GitHub 官方 github-mcp-server（本地部署模式） |
| 运行形态 | 本地进程 / stdio |
| 配置模板 | `mcp-github/.env.template` |
| 配置项 | 实例地址（github.com / GHES）、PAT、可选组织/仓库范围 |
| 规划能力 | 仓库与文件读取、Issue、PR、Workflow 触发等（按官方实现暴露） |
| 连通测试 | 查询当前授权用户（只读探活） |
| 约束 | 不使用官方远程托管 MCP 端点作为主路径 |
| 已验证版本 | 待 M6 回填 |
| 已知限制 | 待 M6 回填（GHES 版本兼容性） |

## 3. mcp-jenkins（Jenkins CI，零插件）

| 项 | 内容 |
|---|---|
| 选型 | 社区独立 jenkins-mcp（REST API 远程调用） |
| 运行形态 | 本地 stdio |
| 配置模板 | `mcp-jenkins/jenkins_config.sample.json` |
| 配置项 | 实例地址、用户名、API Token、可选多实例、只读模式开关 |
| 规划能力 | 查询 job/构建/日志/队列；触发构建等写操作默认二次确认 |
| 侵入性 | **不在 Jenkins 安装插件、不修改实例配置** |
| 连通测试 | 查询 Jenkins 概览或当前用户信息（只读） |
| 已验证版本 | 待 M7 回填 |
| 已知限制 | 待 M7 回填（不同 Jenkins 版本 API 行为差异） |

## 4. mcp-atlassian（Jira + Confluence 一体化）

| 项 | 内容 |
|---|---|
| 选型 | 社区本地一体化 Atlassian MCP（DC/Server） |
| 运行形态 | 本地 stdio |
| 配置模板 | `mcp-atlassian/atlassian_config.sample.json` |
| 配置项 | Jira 地址、Confluence 地址、个人访问令牌、可选空间/项目范围 |
| 规划能力 | Jira 工单搜索/读写；Confluence 页面搜索/读写；工具按命名空间区分 |
| 连通测试 | 分别对 Jira、Confluence 只读探活 |
| 已验证版本 | 待 M8 回填 |
| 已知限制 | 待 M8 回填（DC/Server 兼容性、读写权限范围、支持的 API 范围） |

## 5. 通用配置约定

- 模板中所有敏感字段以占位符（如 `<your-token>`）表示，不得填真实值入库。
- 本地配置文件命名与模板对应，去掉 `.sample`/`.template`，由 `.gitignore` 排除。
- 新增配置项时，同步更新本文件对应服务表格与配置模板。
